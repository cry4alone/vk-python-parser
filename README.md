# Steam Download Monitor

Мониторинг загрузки игр в Steam в фоновом режиме.  
Скрипт отслеживает скорость, статус и название текущей загружаемой игры — **независимо от места установки Steam**.

## Что делает скрипт
- Читает лог `content_log.txt` из папки Steam (находит путь через реестр Windows).
- Каждую минуту выводит в консоль:
  - Название игры (из `appmanifest_*.acf`)
  - Скорость загрузки (в Mbps и MB/s)
  - Текущий статус: `installing`, `stopped`, `unknown`
- Работает до 5 минут или пока активная загрузка не завершится.

## Зависимости
- Python 3.7+
- Windows (требуется доступ к реестру и файловой системе)

## Как запустить
```bash
python main.py
```
